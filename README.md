# study-timer-with-ai-final-version
Built with Qwen Coder and Claude, this offline-first study app solves math locally and routes science queries to Gemini AI. It boosts productivity with a gamified 3D focus garden, calming music, and a distraction tracker that scores your habits. It also includes custom themes, flashcards, and instant notes generated from YouTube links
